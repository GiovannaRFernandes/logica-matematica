Acesso Seguro
Projeto desenvolvido para a APS da disciplina de Lógica Matemática. A proposta era criar um verificador de acesso inspirado no sistema de login do Gov.br.
Como funciona
O sistema é composto por duas etapas de verificação. Na primeira, o usuário insere sua senha. Se ela estiver correta, avança para a segunda etapa, onde são exigidas a verificação biométrica, facial ou digital, e a confirmação do token recebido via e-mail.
Proposição lógica
A situação é representada pela proposição: p ∧ (q ∨ r) ∧ s

p = senha correta
q = reconhecimento facial aprovado
r = digital reconhecida
s = token confirmado
